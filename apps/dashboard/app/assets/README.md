# Google sign-in button

`google-sign-in-light.png` is the unmodified Android + Web, light, rectangular,
text button at 2x resolution from Google's [pre-approved branding assets](https://developers.google.com/static/identity/images/signin-assets.zip),
downloaded on 2026-10-15. It follows Google's [sign-in branding guidelines](https://developers.google.com/identity/branding-guidelines)
and is displayed at 180 × 40 CSS pixels. The image includes the approved font
and coloured logo; no remote font, image or Google script is loaded.
